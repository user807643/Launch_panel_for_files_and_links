## Запуск программ
Портативная программа для Windows, которая запускает нужные файлы/ссылки по нажатию кнопок.
Кнопка зелёная при успешном запуске и красная при неудаче.

## Быстрый старт
1. Положите `exe` в любую обычную папку, например `D:\Утилиты\`
2. Запустите файл дважды щёлкнув по нему.
3. Щёлкните по кнопке правой кнопкой мыши, выберите **«Изменить путь…»** и впишите путь
   к файлу или ссылку на сайт (или **«Обзор файла…»** — системный диалог выбора).
4. Щёлкните по кнопке левой кнопкой мыши — файл запустится, кнопка станет зелёной.
5. Кнопку можно перетащить в любое место окна: зажмите на ней колесо мыши и ведите.
   Без колеса — пункт **«Переместить»** в меню правой кнопки, дальше тяните левой.
6. Размер окна меняется обычным образом: тяните за край или разверните на весь экран.
   `F11` — полный экран, `Esc` или `F11` — обратно в окно. Размер запоминается.

Пути сохраняются автоматически в `settings.json` рядом с программой — при следующем
запуске вводить их заново не нужно.

Не кладите программу в `Program Files` или в папку OneDrive — там может не быть
прав на запись. Программа это распознает, покажет предупреждение в строке состояния
и переедет в `%APPDATA%\Запуск программ`. Чтобы сохранить портативность, держите её
в обычной папке.

## Возможности

| Функция | Описание |
|---|---|
| Запуск любых файлов | `.exe`, `.bat`, `.txt`, `.pdf`, `.lnk` — всё, что Windows умеет открывать двойным щелчком |
| Ссылки в браузере | Адрес вида `https://…`, `www.…` или `website.ru` открывается в браузере Windows по умолчанию |
| Перемещение кнопок | Кнопка едет за зажатым колесом мыши, позиция сохраняется между запусками. Без колеса — пункт «Переместить» в меню правой кнопки |
| Размер окна | Окно тянется за край, разворачивается на весь экран; `F11` — полный экран, `Esc` — назад. Размер и разворот запоминаются |
| Цветовая индикация | Зелёный `#3CB371` — запуск удался. Красный `#E53935` — не удался |
| Возврат в зелёный | Если путь был неверным, после исправления кнопка снова станет зелёной |
| Правка на кнопке | Поле ввода встаёт ровно на место кнопки: путь и имя правятся без отдельной панели |
| Переименование | Пункт «Переименовать…» в меню правой кнопки; пустое имя возвращает «кнопка N» |
| Выбор файла | Пункт «Обзор файла…» открывает системный диалог выбора файла |
| Сохранение путей | Между запусками, в `settings.json` рядом с программой |
| Добавление кнопок | Правкой конфига, без правки кода и пересборки |
| Масштаб экрана | Корректно работает при масштабировании Windows 100–200% |
| Понятные ошибки | Раздельные сообщения: «файл не найден», «путь или ссылка не заданы», «запустить не удалось», «ссылку открыть не удалось» |

## Конфигурация: `settings.json`

Файл создаётся автоматически при первом запуске рядом с программой.

### Поля кнопок

| Поле | Назначение |
|---|---|
| `text` | Надпись на кнопке |
| `path` | Полный путь к файлу или ссылка на сайт. У пути в JSON обратный слэш удваивается: `C:\\папка\\файл.exe`; ссылка пишется как есть: `https://website.ru` |
| `x`, `y` | Положение кнопки в окне. Появляется после первого перемещения; если не задано, считается по `first_row_y` и `row_pitch` |

### Как добавить третью кнопку

Окно автоматически станет выше. Правка кода и пересборка `.exe` не нужны.

Допишите объект в список `buttons` и перезапустите программу:

```json
{ "text": "кнопка 3", "path": "C:\\Мои программы\\утилита.exe" }
```

### Настройки оформления

- `window_width`, `window_height` — размер окна. Записываются сами при изменении размера;
  `window_height: 0` — взять высоту из раскладки (при двух кнопках 529, дальше окно растёт
  само при добавлении кнопок).
- `window_maximized` — окно открывать развёрнутым. Ставится само, когда окно разворачивают,
  и снимается, когда возвращают в обычный вид. Полноэкранный размер (F11) не сохраняется.
- При первом запуске без конфига создаются две кнопки, как на эскизе.
- Если файл настроек повреждён, он сохраняется как `settings.json.bak`, программа
  запускается со значениями по умолчанию и сообщает об этом в строке состояния —
  данные не теряются молча.

## Сборка `.exe` из исходников

**Требование:** `Python 3.13` с библиотекой `tkinter` от [python.org](https://www.python.org/)

Внутрь упакованы Python и tkinter, поэтому Python на машине пользователя не требуется.

```bat
python -m PyInstaller --noconfirm --clean --onefile --noconsole ^
  --name "ЗапускПрограмм" ^
  --distpath "dist" --workpath "build" --specpath "build" ^
  "ЗапускПрограмм.py"
```

## FAQ

- **SmartScreen пишет «неизвестный издатель» при первом запуске.**
Файл не имеет цифровой подписи, для неподписанных программ это обычное поведение.
Нажмите «Подробнее» → «Выполнить всё равно». Подпись кода стоит денег и для личного
использования обычно не оформляется.

- **Кнопка стала красной, хотя файл существует.**
Посмотрите строку состояния внизу окна — там указана конкретная причина. Частые случаи:
файл требует прав администратора, файл заблокирован антивирусом, путь ведёт на отключённый
сетевой диск. Запуск с правами администратора сама программа не выполняет.

- **Пути не сохранились.**
Программа оказалась в папке без прав на запись. Проверьте строку состояния при запуске:
там будет указан настоящий путь к `settings.json` в `%APPDATA%`.

- **Можно ли перенести папку на другой компьютер?**
Да. Скопируйте всю папку вместе с `settings.json` — настройки подхватятся на новом месте.
Проверено запуском из папки с пробелами и русскими буквами в пути.

- **Антивирус ругается на `.exe`.**
Самодельные сборки PyInstaller иногда вызывают ложные срабатывания. Если это мешает,
запустите программу как скрипт: `python ЗапускПрограмм.py`.

## Технические подробности

- **Язык:** Python 3.13 + tkinter (стандартная библиотека), без внешних зависимостей.
- **Сборка:** PyInstaller `--onefile --noconsole`.
- **Только кнопки:** ни заголовка внутри окна, ни подписей сбоку нет — название
  программы видно в заголовке окна, а путь и имя правятся правым кликом по кнопке.
- **Ссылки:** если значение не существует как файл и похоже на адрес (есть схема
  `http`/`https`, префикс `www.` или домен с точкой), оно открывается через
  `os.startfile` — то есть в браузере Windows по умолчанию. Значения с пробелами
  и обратными слэшами считаются путями, поэтому `C:\папка\файл.exe` не спутать со ссылкой.
- **Перемещение:** нажатие `<Button-2>` (колесо) запоминает смещение курсора внутри кнопки,
  `<B2-Motion>` переставляет её через `place`, `<ButtonRelease-2>` сохраняет координаты
  в `settings.json` (в пикселях макета, поэтому позиция переживает смену масштаба экрана).
  Кнопка не выходит за границы окна.
- **Размер окна:** окно растягивается (`resizable`), `<Configure>` запоминает размер
  обычного окна и подтягивает кнопки, если после сжатия они оказались за границей.
  Полный экран — атрибут `-fullscreen` по `F11`; выход — `Esc` или `F11`.
- **Путь к программе** определяется через `sys.executable`, а не `sys.argv[0]`.
  При сборке в один файл распаковка идёт во временную папку, и `sys.argv[0]` указал бы
  не туда — конфиг уехал бы в `%TEMP%`.
- **Сохранение конфига** атомарное: сначала пишется временный файл, затем он подменяет
  основной. Обрыв записи не испортит настройки.
- **Правка на кнопке:** поле `tk.Entry` ставится через `place()` в прямоугольник кнопки,
  поэтому отдельной панели и кнопки «…» в окне нет. Рамка поля окрашена в цвет кнопки,
  длинный путь прокручивается к концу — видно имя файла.
- **Горячие клавиши** в поле правки обрабатываются по управляющему символу (`\x01`, `\x03`, `\x16`, `\x18`),
  а не по `keysym`. Windows передаёт `Ctrl+буква` по позиции латинской клавиши, поэтому
  штатные привязки Tk при русской раскладке не срабатывают.
- **Масштаб экрана** учитывается через DPI-awareness, окно не размывается.
- **Только Windows.** Использованы `os.startfile` и WinAPI.
