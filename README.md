=======================

запуск файлов с окна

=====

## Запуск программ
Портативная программа для Windows, которая запускает нужные файлы по нажатию кнопок.
Кнопка зелёная при успешном запуске и красная при неудаче.

---

## Быстрый старт
1. Положите `exe` в любую обычную папку, например `D:\Утилиты\`
2. Запустите файл дважды щёлкнув по нему.
3. Укажите путь к нужному файлу — впишите вручную или нажмите кнопку **«…»** справа от поля.
4. Нажмите кнопку слева. Файл запустится, кнопка станет зелёной.

Пути сохраняются автоматически в `settings.json` рядом с программой — при следующем
запуске вводить их заново не нужно.

> **Важно.** Не кладите программу в `Program Files` или в папку OneDrive — там может не быть
> прав на запись. Программа это распознает, покажет предупреждение в строке состояния
> и переедет в `%APPDATA%\Запуск программ`. Чтобы сохранить портативность, держите её
> в обычной папке.

## Как это выглядит

```
        Запуск программ

  ┌──────────────────┐   ┌────────────────────────────────┐
  │    кнопка 1      │ р │ C:\Program Files\Мой файл.exe  │ […]
  └──────────────────┘ е └────────────────────────────────┘
                       д
  ┌──────────────────┐ . ┌────────────────────────────────┐
  │    кнопка 2      │ 2 │ D:\Документы\инструкция.txt    │ […]
  └──────────────────┘   └────────────────────────────────┘
```

Подписи «ред. 1», «ред. 2» расположены вертикально, как на макете.

## Возможности

| Возможность | Описание |
|---|---|
| Запуск любых файлов | `.exe`, `.bat`, `.txt`, `.pdf`, `.lnk` — всё, что Windows умеет открывать двойным щелчком |
| Цветовая индикация | Зелёный `#3CB371` — запуск удался. Красный `#E53935` — не удался |
| Возврат в зелёный | Если путь был неверным, после исправления кнопка снова станет зелёной |
| Выбор файла | Кнопка **«…»** открывает системный диалог выбора файла |
| Сохранение путей | Между запусками, в `settings.json` рядом с программой |
| Добавление кнопок | Правкой конфига, без правки кода и пересборки |
| Масштаб экрана | Корректно работает при масштабировании Windows 100–200% |
| Понятные ошибки | Раздельные сообщения: «файл не найден», «путь не указан», «запустить не удалось» |

### Горячие клавиши в поле пути

| Клавиши | Действие |
|---|---|
| `Ctrl+A` | Выделить весь путь |
| `Ctrl+C` | Копировать |
| `Ctrl+V` | Вставить путь |
| `Ctrl+X` | Вырезать |

Работают при **русской и английской** раскладке одинаково. При вставке из проводника
кавычки и переводы строки убираются автоматически — путь не нужно чистить руками.

Поддерживается и обычная вставка через правую кнопку мыши.

## Конфигурация: `settings.json`

Файл создаётся автоматически при первом запуске рядом с программой.

```json
{
  "settings": {
    "title": "Запуск программ",
    "window_width": 950,
    "button_width": 302,
    "button_height": 115,
    "row_pitch": 125,
    "first_row_y": 200,
    "margin_left": 80,
    "gap_button_label": 8,
    "label_width": 40,
    "gap_label_entry": 15,
    "margin_right": 25,
    "browse_width": 44,
    "browse_gap": 10,
    "font_family": "Segoe UI",
    "font_title": 30,
    "font_button": 20,
    "font_label": 17,
    "font_entry": 16,
    "font_status": 14,
    "min_height": 529,
    "bottom_space": 40
  },
  "buttons": [
    { "text": "кнопка 1", "label": "ред. 1", "path": "C:\\Windows\\System32\\notepad.exe" },
    { "text": "кнопка 2", "label": "ред. 2", "path": "D:\\Документы\\инструкция.txt" }
  ]
}
```

### Поля кнопок

| Поле | Назначение |
|---|---|
| `text` | Надпись на кнопке |
| `label` | Вертикальная подпись справа от кнопки |
| `path` | Полный путь к файлу. В JSON обратный слэш удваивается: `C:\\папка\\файл.exe` |

### Как добавить третью кнопку

Допишите объект в список `buttons` и перезапустите программу:

```json
{ "text": "кнопка 3", "label": "ред. 3", "path": "C:\\Мои программы\\утилита.exe" }
```

Окно автоматически станет выше. Правка кода и пересборка `.exe` не нужны.

### Настройки оформления

- `window_width` — ширина окна. При двух кнопках по умолчанию высота 529, как в макете;
  при большем числе кнопок окно растёт само.
- При первом запуске без конфига создаются две кнопки, как на эскизе.
- Если файл настроек повреждён, он сохраняется как `settings.json.bak`, программа
  запускается со значениями по умолчанию и сообщает об этом в строке состояния —
  данные не теряются молча.

## Сборка `.exe` из исходников

Обычному пользователю этот раздел не нужен — готовый `.exe` уже лежит в папке.

Запустите `Собрать_exe.bat`. Скрипт сам проверит окружение, при необходимости
установит PyInstaller и соберёт программу.

**Требование:** Python 3.13 с библиотекой `tkinter` от python.org (стандартная установка).

Встроенный Python из AutoClaw **не подходит** — в нём нет `tkinter`, собрать программу
из него нельзя. Путь к своему интерпретатору при необходимости укажите в переменной `PY`
в начале `Собрать_exe.bat`.

Команда сборки вручную:

```bat
python -m PyInstaller --noconfirm --clean --onefile --noconsole ^
  --name "ЗапускПрограмм" ^
  --distpath "dist" --workpath "build" --specpath "build" ^
  "ЗапускПрограмм.py"
```

Готовый файл появится в папке `dist`. Размер около 10 МБ — внутрь упакованы Python
и tkinter, поэтому Python на машине пользователя не требуется.

## Возможные вопросы

**SmartScreen пишет «неизвестный издатель» при первом запуске.**
Файл не имеет цифровой подписи, для неподписанных программ это обычное поведение.
Нажмите «Подробнее» → «Выполнить всё равно». Подпись кода стоит денег и для личного
использования обычно не оформляется.

**Кнопка стала красной, хотя файл существует.**
Посмотрите строку состояния внизу окна — там указана конкретная причина. Частые случаи:
файл требует прав администратора, файл заблокирован антивирусом, путь ведёт на отключённый
сетевой диск. Запуск с правами администратора сама программа не выполняет.

**Пути не сохранились.**
Программа оказалась в папке без прав на запись. Проверьте строку состояния при запуске:
там будет указан настоящий путь к `settings.json` в `%APPDATA%`.

**Можно ли перенести папку на другой компьютер?**
Да. Скопируйте всю папку вместе с `settings.json` — настройки подхватятся на новом месте.
Проверено запуском из папки с пробелами и русскими буквами в пути.

**Антивирус ругается на `.exe`.**
Самодельные сборки PyInstaller иногда вызывают ложные срабатывания. Если это мешает,
запустите программу как скрипт: `python ЗапускПрограмм.py`.

## Технические подробности

- **Язык:** Python 3.13 + tkinter (стандартная библиотека), без внешних зависимостей.
- **Сборка:** PyInstaller `--onefile --noconsole`.
- **Вертикальные подписи:** `Canvas.create_text(..., angle=90)`. Обычный `Label` текст
  не поворачивает, поэтому подписи нарисованы на `Canvas`.
- **Путь к программе** определяется через `sys.executable`, а не `sys.argv[0]`.
  При сборке в один файл распаковка идёт во временную папку, и `sys.argv[0]` указал бы
  не туда — конфиг уехал бы в `%TEMP%`.
- **Сохранение конфига** атомарное: сначала пишется временный файл, затем он подменяет
  основной. Обрыв записи не испортит настройки.
- **Горячие клавиши** обрабатываются по управляющему символу (`\x01`, `\x03`, `\x16`, `\x18`),
  а не по `keysym`. Windows передаёт `Ctrl+буква` по позиции латинской клавиши, поэтому
  штатные привязки Tk при русской раскладке не срабатывают.
- **Масштаб экрана** учитывается через DPI-awareness, окно не размывается.

## Известные ограничения

- **Только Windows.** Использованы `os.startfile` и WinAPI, на Linux и macOS программа
  работать не будет.
- **Кнопки прямоугольные.** Скруглённые углы из макета не воспроизводятся: в tkinter
  для этого нужна ручная отрисовка и свои обработчики нажатий. Согласовано при постановке.
- **Нет запуска от администратора.** Если файл требует повышения прав, Windows покажет
  запрос UAC, либо запуск не состоится.
- **Одна строка на кнопку.** Структура «кнопка — подпись — путь — выбор файла» фиксированная.
